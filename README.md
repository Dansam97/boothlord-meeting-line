Entry for the make.fun bounty [The Meeting That Should Have Been One Line](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c): one line, at most 200 characters — the single sentence that could have replaced an entire pointless meeting. The program writes the line to `entry.txt` in the output directory:

> This meeting could have been an email, and the email could have been a shrug.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
